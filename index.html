About Me (Professionally)

My background in Biological and Agricultural Engineering has supported me through my less obvious path towards computational data science. I find myself relying on practical intuition gained from basic engineering training and regularly applying the scientific method at work and in everyday life. Using this foundation, I have built and contributed to research projects that use available data as a basis for decisions—driving actions for the future with lessons from the past. An important focus for me is ensuring that my understanding of the issue is solid. I find that involving stakeholders early on in the process helps tremendously with this and can also provide a great starting point for framing the findings in a way that highlights their relevance to the decision maker.

Featured Projects

ABM Scale-Up
Highlights:
  • high-performance agent-based modeling
  • scalable simulation
  • GPU computing

The Deep Graph Library Poverty Trap Model (DGL-PTM) is part of an ongoing effort in collaboration with the Netherlands eScience Center to create an Agent Based Model (ABM) framework that supports communication between agents in a network with a population on the scale of millions. Supporting elements from the Deep Graph Library, particularly message-passing, enabled us to leverage matrix operations on GPUs to achieve the necessary capacity.

Role: keeping the project on track towards research goals, balancing the ideas of the PI and the eScience team to keep things progressing, and eventually taking a greater role as a developer when administrative upheaval impeded the team's ability to continue.

Experience gained with: PyTorch, DGL, GitHub collaboration (big one!), software verification (static analysis, model checking, unit testing), HPC job scheduling, API documentation, socioeconomic ABMs

Existing skills exercised: experimental design, technical writing, Python, pandas, NumPy, matplotlib, seaborn

Cabinette Analytics & BI
Highlights:
  • independent project management
  • geospatial analytics
  • business intelligence
  • end-to-end product development
  • data-driven decision support

This project is a comprehensive demonstration of my capabilities in independent project management. It is also a showcase of my skills in the context of developing tools for the formation and visualization of business insights. Inspired by my own difficulty finding accommodation that suited my needs, I set out to create a product that could inform site placement of budget cabinettes near U.S. National Parks and Monuments. It has been an excellent exercise in proper documentation. Although it may be very far in the future, one day, I hope to find the investment required to actualize the concept. The first MS PowerBI iteration was completed on schedule in September 2025. A new iteration of the project was envisioned with a fully online dashboard and is currently live (see project log for progress here).

Role: leading the project from inception to completion and ensuring timely delivery of project milestones

Experience gained with: DMAIC principles, PostgreSQL, Power BI, TypeScript, React

Existing skills exercised: project management, problem framing, product development, database querying, data cleaning, data engineering, dashboard development, UX design, Agile methodology, geospatial analytics, APIs

MLP Equation Replacement
Highlights:
  • neural networks
  • model acceleration with machine learning
  • model training

This project was inspired by a need established when scaling up DGL-PTM. the function modeling agent decisions became a tremendous bottleneck. As a replacement, I developed a Multi-Layer Perceptron (MLP) that predicts the outputs of the original Bellman equation approximation with an efficacy that made it a viable replacement.

Role: picking a direction for the replacement function, developing a methodology for selecting a model, conducting the training and testing

Experience gained with: Machine Learning, algorithmic documentation

Existing skills exercised: PyTorch, experimental design, technical writing, Python, pandas, NumPy, matplotlib, seaborn, HPC job scheduling, LaTeX

Climate Dashboard

This project from my Ph.D. was one of my first efforts in dashboard development. It was extra gratifying because it was made available to a broader audience. Designed as a simple tool to geographically organize data available to the project which spanned across three countries in East Africa, the dashboard also came to include aggregated summaries of the data,serving as a communication tool for the project team and stakeholders. While the dashboard itself is no longer available and is, as a 2021 project, outdated, it was a great learning experience which allowed me to explore what I now acknowledge as a small subset of the possibilities of interactive visualizations.

Role: picking a platform for the dashboard, determining its scope given the available resources, testing the dashboard with stakeholder feedback, arranging for the app deployment with the help of the Purdue Research Computing team

Experience gained with: dashboard development, flexdashboard, Shiny, dygraphs, leaflet

Existing skills exercised: data structuring, database querying, data cleaning, merging data sources, bias correction, R, Plotly, GIS, dplyr, stakeholder communication

AI Assistant
Highlights:
  • conversational AI
  • cloud computing and deployment
  • LLM integration
  • prompt engineering

This project features Lenny, a conversational AI assistant designed to help visitors to this website. Lenny served well as a practical way of exploring the possibilities of cloud computing and LLMs (large language models). The assistant is available for use below. Lenny was implemented through the integration of an Azure Foundry AI (GPT-4.1-mini) and Azure AI Search services (orchestrated within an Azure Function). The AI Search service indexes documents pertaining to my work and expertise, allowing the assistant to give contextually relevant responses to user queries.

Role: requirements gathering, technology selection, solution architecture, Azure resource management, end-to-end implementation (Python, Azure Functions, AI Search, OpenAI/Foundry), integration of conversational AI and semantic search, deployment, user experience testing, and iterative improvement.

Experience gained with: cloud computing, API development, Azure, conversational AI, LLM integration, semantic search indices, CI/CD automation, managing secrets

Existing skills exercised: python, version control, static analysis, unit testing, project management, UX design, HTML, CSS, JS
