WindBorne Challenge Response

Hello, I have addressed the specified challenge questions below. Thank you for your time. Please feel welcome to check out some of the projects in my portfolio. AI-assisted climate data analysis is an area I am particularly interested in, and I would be happy to chat about it.

  • Q: Tell us about a problem you couldn’t leave alone. What did you build to fix it?
  • A: I am currently renting an apartment with venetian blinds that let an amount of light in that made it difficult to sleep. Since I had a three month lease and a spare blackout curtain, I decided it was worthwhile to find a non-damaging way of hanging the curtain. I purchased a special foam board long enough to accommodate the window width, a curtain track system with an adhesive backing, and my favorite command strips, careful to stay within my $20 budget. I attached the track system to the foam board and used the command strips to adhere the foam board above the window. Success! You may be wondering why I 1) didn't just stick the curtain track system straight to the wall or 2) use a traditional curtain rod. Regarding 1, it was mainly because I have had very bad experiences with cheap adhesive residue in the past. Regarding 2, I didn't want to purchase a drill or patch up the resulting wall-anchor holes for such a short-term stay.
  • Q: Tell us about a time you had to understand an unfamiliar system that wasn’t behaving as expected. How did you get to the bottom of it?
  • A: Last month, I decided to make a switch to a new database host for an active web application. The new connection string was exactly as specified by the provider, but the application was not able to retrieve data as expected in local testing. I turned to basic diagnostics. The DNS name was resolving, and the network connectivity was sound. Then, I noticed that the previous database url used a pooler, while the new connection string did not. I remembered that the new database host also offered a pooler to resolve IPv4 versus IPv6 mismatches. I updated the connection string to use the pooler, allowing for a successful transition and redeployment.
  • Q: Describe a real coding task where AI tools helped you move faster. Where did you have to step in and think for yourself?
  • A: I would say that AI tools have made a tremendous difference in opening up the possibilities of what I can achieve as an individual. For example, I was able to develop a RAG LLM assistant for my portfolio when I had very little prior experience with their design. I relied on AI tools for initial code templates, explanations of new terms so that I would know what to research further, and comparisons of pros and cons when faced with a decision. Ultimately, I maintained responsibility for tool and resource selection, design, and code testing and refinement (project overview).
